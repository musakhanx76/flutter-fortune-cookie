# 🥠 Fortune Cookie App

A simple Flutter application built as part of my mobile development learning journey. The app generates random fortunes and quotes at the tap of a button.

## ✨ Features
* Interactive UI with dynamic fortune updates
* Styled with custom `Card` widgets and Material Design
* Responsive layout for mobile devices

## 🛠️ Built With
* **Flutter** - UI Toolkit
* **Dart** - Programming Language
